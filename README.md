# API Benchmark Tool

This project is an API Benchmark Tool that allows users to test the performance of their APIs by sending customizable requests and displaying the results in real-time.

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/uttamribadiya16/api-benchmark-tool.git
    cd api-benchmark-tool
    ```

2. Install the dependencies:
    ```sh
    npm install
    ```

## Usage

1. Start the development server:
    ```sh
    npm run dev
    ```

2. Open your browser and navigate to `http://localhost:5173` to see the application.

## Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the project for production.
- `npm run lint`: Lints the project files using ESLint.
- `npm run preview`: Previews the production build.
